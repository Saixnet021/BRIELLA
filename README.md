# BRIELLA Joyería 💎

Sitio web y catálogo online oficial para **BRIELLA Joyería**.

## ✨ Características
- Catálogo interactivo de joyas y accesorios (Anillos, Collares, Pulseras, Aretes, etc.).
- Filtros por categoría y búsqueda en tiempo real.
- Integración directa para pedidos y consultas por WhatsApp.
- Diseño moderno, elegante y completamente responsive.

## 🚀 Tecnologías
- [Astro](https://astro.build/)
- [Tailwind CSS](https://tailwindcss.com/)
- JavaScript

## 📦 Instalación y Desarrollo

1. Instalar dependencias:
```bash
npm install
```

2. Iniciar servidor local:
```bash
npm run dev
```

3. Compilar para producción:
```bash
npm run build
```
